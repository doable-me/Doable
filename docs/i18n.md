# English and Simplified Chinese UI

This opt-in Chinese interface keeps English as the default. The language selector
stores `en` or `zh-CN` in the non-sensitive `doable_locale` cookie and synchronizes
other tabs through a locale-only localStorage event. Signed-in users also persist
their preference through `PATCH /auth/me/language`; migration 104 adds the nullable
`users.interface_language` field. A failed save keeps the current choice and shows an error. `next-intl` is pinned to 4.14.8.

UI calls use explicit `ui(...)` lookups into `apps/web/messages/{en,zh-CN}.json`.
`source.json` records source locations and `index.json` maps source text to stable
keys. Dynamic UI phrases use ICU interpolation. `translateUiData` only translates
specified display fields of static configuration; IDs, callbacks, filenames,
URLs, user content and raw technical logs are preserved. Runtime status mapping
only matches known server-authored phrases. No DOM translation or external
translation service runs in the product.

## Validation

```sh
pnpm exec tsx --test scripts/i18n/test.ts
pnpm --filter @doable/web type-check
pnpm --filter @doable/web lint
pnpm --filter @doable/web build
```

Also verify language changes with a dialog open, reload persistence, authentication,
the editor, settings and administrator pages in a real browser. Automated catalog
checks do not establish complete translation coverage.

## Scope and remaining review

Includes dashboard/editor/settings/admin UI, dialogs, notifications, fixed system
prompt envelopes and dynamic tool/build/preview statuses. Historical user/AI prose
is not rewritten. English landing/legal content and database-supplied template
names/descriptions remain unchanged. This is a broad initial localization patch;
terminology and uncovered nested flows need maintainer review. There is no
organization-specific branding, domain, credential or forced Chinese AI prompt.

## Entry points and interaction

Public authentication pages expose an easy-to-find top selector. Signed-in users
can switch from the account menu or Settings → General; the editor uses its global
More Views menu. There is no overlay inside the generated app preview. Native
language names and labeled 44px controls work on mobile and with a keyboard.

Changing interface language refreshes translated server components without a hard
reload. It must preserve unsent drafts, open dialogs and active generation; it
does not submit or restart work. AI responses and generated-app language remain
controlled by their own prompts. Explicit account preferences override the default
on sign-in; this does not assert a full cross-device E2E test.
